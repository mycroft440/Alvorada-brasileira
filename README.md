# Alvorada Brasileira 🇧🇷

App Android para rastreamento de leis, obras públicas e participação cidadã.

## Funcionalidades
- 📜 **Rastreamento de Leis e Emendas**: Fique por dentro do que está sendo votado.
- 🏗️ **Fiscalização de Obras**: Acompanhe o progresso e os gastos de obras públicas.
- 🗳️ **Pesquisas Públicas**: Dê sua opinião sobre projetos de lei e melhorias para a cidade.

## Tecnologias
- Kotlin
- Jetpack Compose
- Material 3
- Clean Architecture
